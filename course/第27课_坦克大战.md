# 第27课：90坦克大战 🎮

> 经典红白机游戏，用 Python 复刻！

## 这节课学什么？

1. **游戏主循环**：像动画片一样，一帧一帧地刷新画面
2. **键盘控制**：方向键让坦克动起来
3. **碰撞检测**：子弹打中墙、打中坦克会消失
4. **列表管理**：用列表存放所有子弹和敌军坦克

---

## 怎么运行？

先在项目里安装 pygame（只需做一次）：

```bash
cd leo_learn_course
python3 -m venv .venv
.venv/bin/pip install pygame
```

然后启动游戏：

```bash
.venv/bin/python course/tank_battle.py
```

---

## 操作说明


| 按键      | 功能      |
| ------- | ------- |
| ↑ ↓ ← → | 移动坦克    |
| 空格      | 发射子弹    |
| P       | 暂停 / 继续 |
| R       | 重新开始 |


---

## 游戏规则

- 🛡️ **保护基地**：地图下方黄色小房子是你的基地，不能被敌军打到！
- 🔫 **消灭敌军**：一共 6 辆敌军坦克，全部击毁就胜利
- ❤️ **三条命**：玩家有 3 条生命，被击中会复活，命用完就失败
- 🧱 **砖墙可打穿**：橙色砖墙会被子弹打碎
- ⛓️ **钢墙打不穿**：灰色钢墙子弹打不坏

---



## 核心代码思路



### 1. 游戏主循环

```python
while running:
    # 1. 处理按键
    # 2. 更新位置（坦克、子弹）
    # 3. 检查碰撞
    # 4. 重新画一遍屏幕
    clock.tick(60)  # 每秒 60 帧
```



### 2. 地图用字符串表示

```
"#" = 砖墙    "." = 空地
"B" = 基地
```



### 3. 子弹类

子弹每帧沿一个方向移动，碰到东西就 `alive = False`。
