## 课表（14 课）

| 课 | 记住什么 |
| :--- | :--- |
| 图形化编程 | 拼积木；绿旗开始；自制积木=函数；先做好再叫 |
| 从上往下做 | 上面先、下面后；换顺序结果会变 |
| 如果积木 | 对了才做；否则只走一条；里面还能再放如果 |
| 再做一遍 | 重复；圈里还能有圈；和如果不一样 |
| 侦测小眼睛 | 碰到、询问并等待；超声波看远近；计时器也算侦测 |
| 小盒子变量 | 赋值=放进去；新的盖住旧的；说出来不改 |
| 并且或者不是 | 并且要两个都对；或者有一个就行 |
| 数字会算 | 加减；大于更小；括号先算 |
| 套娃积木 | 自己叫自己；一定要能停下 |
| 盘子叠叠乐 | 后放的先拿；只能拿最上面；排队不是栈 |
| 名字小本本 | 用名字找东西 |
| 一排小格子 | 从一号数；一个一个看叫遍历 |
| 一层一层找 | 先近后远（广度） |
| 一条路走到底 | 走到头再退回来（深度） |

听完再去做 **闯关小测验**。
