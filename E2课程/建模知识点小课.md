# E2 知识点小课 · 先听再选 📚

网页关卡：`e2.html` → **📚 知识点小课**

来源是家长给的两份资料包：**建模大赛.zip**、**建模11-18.zip**（问卷星练习）。  
原题面向中高年级，文字很长。小鱼这一页 **先听短故事，再点选择题**，不背英文缩写，不写代码。

打开网页后先点 **「我要听」**，喇叭才会说话。

## 怎么用

1. 首页点 **📚 知识点小课**  
2. 选一课：上面几页是讲解，后面才是选择题 / 判断题  
3. 选错了可以再选。听完一课，卡片上会亮星  
4. 全部听过之后，再去 **⭐ 闯关小测验** 做整套 30 题

## 课表（16 课）

### 建模大赛（图形化 + 科学）

| 课 | 小鱼记住什么 |
| :--- | :--- |
| 图形化编程 | 拼积木；绿旗开始；自制积木是打包好的小工具 |
| 从上往下做 | 上面的先做，下面的后做 |
| 如果积木 | 对了才做；那么和否则只走一条 |
| 再做一遍 | 重复；圈圈里还可以有圈圈 |
| 小盒子变量 | 盒子有名字，里面放数字 |
| 并且或者不是 | 并且要两个都对；或者有一个就行 |
| 数字会算 | 加会变多，减会变少；大于就是更大 |
| 科学常识加练 | 热气球、空心船、铁锅抹油、醋和小苏打 |

### 建模 11–18（故事版）

| 课 | 小鱼记住什么 |
| :--- | :--- |
| 侦测小眼睛 | 碰到、询问并等待；超声波看远近，不看颜色 |
| 探究和模型 | 模型要简单；做好了要点绿旗试；一次只改一个 |
| 套娃积木 | 自己请自己再做一次；一定要能停下 |
| 盘子叠叠乐 | 后放上去的先拿下来 |
| 名字小本本 | 用名字找到东西 |
| 一排小格子 | 排成一排，一个一个看 |
| 一层一层找 | 先找身边的，再找更远的 |
| 一条路走到底 | 走到底，不通再退回来换路 |

广度 / 深度、递归、栈、字典、列表，考试若出现，按上面的图画来选即可。不要给一年级讲图论。
