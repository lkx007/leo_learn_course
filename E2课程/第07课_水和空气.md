# E2 第07课：水和空气 💧

网页关卡：`e2.html` → **💧 水和空气**

来自三年级科学复习，改成小鱼能听懂的短故事。  
不要背名词。能指对图、能说出「因为」即可。

## 水会变戏法

1. **会跑的水** — 水没有固定样子，倒进杯子就变成杯子的样子。  
2. **白汽不是气** — 壶嘴白白的，是小小的水滴。真正的水蒸气，眼睛看不见。  
3. **冰宝宝变胖** — 水结成冰，占的地方变大；冰化成水，又变小。  
4. **盐会藏** — 搅拌、加热、压碎，盐藏进水里更快。沙子和油藏不进去。  
5. **水宝宝逃走** — 晒太阳、吹风、把水摊开，水逃得更快（蒸发）。

积木模型：背景换成「太阳 + 风扇」，水滴角色慢慢隐身。

## 空气和风

1. **杯子里的空气** — 杯子倒扣进水里，杯底的纸常常不湿，因为空气占着地方。  
2. **空气有重量** — 皮球再打一点气，天平会歪。  
3. **风是怎么来的** — 热空气往上跑，冷空气来补空，空气流动就是风。  
4. **下午更热** — 一天里下午两三点常常最热。  
5. **雪也是水** — 雨、雪、冰雹都是从天上掉下来的水。

## 蚕宝宝和太阳

1. **蚕换衣服** — 卵 → 幼虫 → 蛹 → 成虫；最爱吃叶子的是幼虫。  
2. **卵生和胎生** — 鸡下蛋；狗是妈妈生下来、吃奶长大。  
3. **谁更快** — 跑一样远，用的时间少就更快。  
4. **海比地大** — 地球上海洋更大；能喝的淡水很少。  
5. **太阳是大灯** — 太阳自己会发光，给地球光和热。

## 家长备注

三年级原题有酒精灯、过滤蒸发、雨量器等操作细节。一年级只保留「为什么」，考试文字题靠听喇叭 + 看汉字拼音。
