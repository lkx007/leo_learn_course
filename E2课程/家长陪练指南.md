## 2. 考什么？（对应网页 8 关）

初赛对一年级孩子，翻译成：

1. **积木软件**：舞台、绿旗、从上往下排  
2. **模型不是真的**；做好了要点绿旗 **试一试**  
3. **拼 → 排 → 试 → 改**  
4. **先看再问再猜再试**；对比实验 **只改一个**  
5. **生活里的为什么**（水、空气、声音、电路……）  
6. **比赛规矩**：两点那场、页面不要关、答完交卷、房间安静

题目用 **汉字 + 拼音**。网页「模拟考」六套 + 幸运卷，对齐 30 题。

## 3. 设备清单（今天晚上或明天上午彩排）

**电脑（考试机）** — 以 E2 指南表格为准

- Windows 10 或 **macOS 11.0** 及以上；**不支持在 Mac 上安装 Windows 来考**  
- 内存 8GB+，C 盘剩 4GB+；CPU 大约 i5 二代 / Ryzen 5 二代以上  
- 浏览器：**只用谷歌 Chrome ≥ 109**（不要 Edge / Firefox / Safari）  
- 键鼠能用，**前置摄像头**能出画面；**插上电源**  
- 建议独享 **50Mbps** 宽带  

**手机或平板（监考机）**

- 摄像头清晰；**微信 ≥ 8.0.30**  
- 和电脑分开摆（以当天指引为准）  
- 作答时 **页面常开**；中途退出可能 **丢掉进度**

**同一平台补充（不要照抄 E4 的 9:00–18:00 窗口）：**

- Chrome 小窗选 **「访问该网站时允许」** 摄像头  
- 脸和上半身在画面里；不要虚拟背景  
- 蓝「模拟比赛」可多次；橙「正式比赛」只在开放时段  
- 如果弹出语言，选 **图形化 / Scratch**，不要选 Python
