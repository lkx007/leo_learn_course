## 2. 考什么？（对应网页 8 关）

初赛四块：图形化编程基础、图形化建模入门、科学探究与建模、基础科学常识。  
对一年级孩子，翻译成：

1. **积木软件长什么样、绿旗干什么、积木为什么要从上往下拼**  
2. **模型不是真的**；用积木把真问题做成小小的、能点绿旗试的模型  
3. **拼 → 排 → 试 → 改**（说明会里的「拼搭—编码—测试—优化」）  
4. **科学家先看再问再猜再试**；对比实验 **只改一个**  
5. **生活里的为什么**（水、空气、声音、电路、光、种子、食物链……）

题目用 **汉字 + 拼音**。网页「模拟考」有六套 20 选 + 10 判（满分 100），加上幸运抽题，对齐初赛题量。

## 3. 设备清单（9/12 晚 + 9/13 上午彩排）

**电脑（考试机）**

- Windows 10 或 **macOS 11.0** 及以上  
- 内存 8GB+，C 盘剩 4GB+；CPU 大约 i5 二代 / Ryzen 5 二代以上  
- 浏览器：**只用谷歌 Chrome ≥ 109**（不要 Edge / Firefox / Safari）  
- 键鼠能用，**前置摄像头**能出画面；笔记本电量充足  
- 建议独享 **50Mbps** 宽带  

**手机或平板（监考机）**

- 摄像头清晰；**微信 ≥ 8.0.30**  
- 和电脑分开摆：电脑拍脸，手机拍侧面/桌面（以当天指引为准）  
- 作答时 **页面常开、监控常开**，关掉可能被判定作弊  

网页课第 1 关有「点亮星星」检查。

## 4. 官网「练」和「赛」（非常重要）

平台上有两个大按钮：

| 按钮 | 做什么 | 次数 |
| :--- | :--- | :--- |
| 蓝 · **模拟比赛（练）** | 熟悉系统、检查摄像头和网络 | 可以再进 |
| 橙 · **正式比赛（赛）** | 真正交卷 | **每人只有一次** |

说明会写了：**比赛没有可计分的模拟考试，正式考试每人只有一次机会。**  
考前请用蓝按钮测设备。不要提前点橙色按钮。

我们网页课里的「练一练 / 模拟考」是给小鱼在家练手的，**不会**替掉官网那一次正式考。
