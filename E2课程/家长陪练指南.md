## 2. 考什么？（对应网页 6 关）

初赛四块，官网原文是：图形化编程基础、图形化建模入门、科学探究与建模、基础科学常识。  
对一年级孩子，翻译成：

1. **积木软件长什么样、绿旗干什么、积木为什么要从上往下拼**  
2. **模型不是真的，是缩小/简化的替身**（玩具、地球仪、Scratch 小游戏）  
3. **科学家先看再问再猜再试**；做对比实验 **只改一个**  
4. **生活里的为什么**：盐会化、冰会化、磁铁认铁、灯要连成圈、植物要太阳、鞋底要花纹……

科学部分结合了小学科学常识复习材料（物质 / 生命 / 地球 / 工程），用来判断「这个积木模型合不合理」。

## 3. 设备清单（考前一天和上午做彩排）

官方 E2 初赛要求（比报名指引更严，以测评指南为准）：

**电脑（考试机）**

- 系统：Windows 10 或 **macOS 11.0** 及以上（不要在 Mac 上装 Windows 去考）
- 内存 8GB+，C 盘剩 4GB+
- 浏览器：**谷歌 Chrome ≥ 109**
- 键鼠能用，**前置摄像头**能出画面
- 建议独享 **50Mbps** 宽带

**手机或平板（监考机）**

- 摄像头能视频通话
- **微信 ≥ 8.0.30**
- 和电脑分开摆：电脑拍脸，手机拍侧面/桌面（以当天页面指引为准）

网页课第 1 关有「点亮星星」检查：浏览器、喇叭、鼠标、网络、摄像头（可跳过）。
