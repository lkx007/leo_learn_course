# E2 闯关小测验 ⭐

网页关卡：`e2.html` → **⭐ 闯关小测验**

初赛结构：**20 道选择题 + 10 道判断题，满分 100 分**。

题都是 **积木编程**（顺序、如果、循环、变量、侦测、函数、栈、列表、字典、广度、深度）加上比赛规矩（两点那场、Chrome、交卷）。没有水、冰、声音、植物题。

| 卷子 | 内容 |
| :--- | :--- |
| 🐟 小鱼卷 | 入门 |
| 🐱 小猫卷 | 换一种问法 |
| 🧩 积木卷 | 舞台、函数、嵌套如果 |
| ⭐ 绿旗卷 | 顺序、循环、逻辑 |
| 👀 侦测卷 | 碰到、传感器、变量 |
| 📦 盒子卷 | 赋值、栈、字典、列表 |
| 🎲 幸运卷 | 从题库抽 30 题 |

1. **练一练**：选错可以再选  
2. **模拟考**：一遍过  
3. 官网橙色「正式比赛」不要提前点
