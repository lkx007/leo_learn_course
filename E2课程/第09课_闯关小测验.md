# E2 第09课：闯关小测验 ⭐

网页关卡：`e2.html` → **⭐ 闯关小测验**

对齐今天说明会的初赛结构：**20 道选择题 + 10 道判断题，满分 100 分**（选择 4 分、判断 2 分）。  

小题库有 **4 套固定卷 + 1 套幸运卷**：

| 卷子 | 给谁先做 |
| :--- | :--- |
| 🐟 小鱼卷 | 第一套，和关卡里的故事最像 |
| 🐱 小猫卷 | 换一种问法，还是这些知识点 |
| 🌈 彩虹卷 | 科学小故事多一点 |
| ⭐ 星星卷 | 再练一遍，带比赛规则 |
| 🎲 幸运卷 | 从题库里抽出 30 题，每次不完全一样 |

题目是 **汉字 + 拼音**。喇叭一句一句说。选完按得分发小奖状。  
这是家里练手用的。官网橙色「正式比赛」**每人只有一次**，不要提前点。

## 怎么用

1. 先点 **「练一练」**：选错可以再选，喇叭会讲为什么。  
2. 考前点 **「模拟考」**：一遍过 30 题，对了加分，错了记下。四套都做过再点幸运卷。  
3. 最后一页看 **得分**（就是百分制）和激励画面：  
   - 90 分以上 → 🏆 超级小鱼冠军  
   - 75 分以上 → 🌟 闪亮小明星  
   - 60 分以上 → 💪 勇敢小探险家  
   - 不到 60 分 → 🐟 不怕，再来一次  
4. 只把错题再听一遍，不要加新知识。

## 考试当天

家长登录测评；先用官网 **蓝色「模拟比赛」** 看摄像头和网络。  
确认无误再点 **橙色「正式比赛」**。  
提醒小鱼：**看字、看拼音、听喇叭、点对的那一个。页面不要关、不要切走。**
