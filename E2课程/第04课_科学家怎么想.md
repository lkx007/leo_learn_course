# E2 第04课：科学家怎么想 🔍

网页关卡：`e2.html` → **🔍 科学家怎么想**

## 五步儿歌（可跟读）

看一看 → 问一问 → 猜一猜 → 试一试 → 说一说

| 步 | 意思 | 小例子 |
| :--- | :--- | :--- |
| 看 | 先睁眼看发生了什么 | 绿豆苗有的高有的矮 |
| 问 | 变成一个问题 | 是不是因为太阳？ |
| 猜 | 先想一个答案 | 我猜要有阳光才长得好 |
| 试 | 做实验（只改一个） | 两盆土、水一样，一盆有阳光 |
| 说 | 根据看到的下结论 | 有阳光的长得壮 |

## 金规则：只改一个

对比实验里，**只能动一个开关**。  
阳光、水、花盆一起改，就不知道是谁的功劳。  
网页里有「哪一盆实验是公平的」点图题。
