# E2 第05课：科学小故事 🌈

网页关卡：`e2.html` → **🌈 科学小故事**

每则故事：**一幅图 + 一句为什么 + 一句「积木可以怎么演」**。  
不要默写名词。能指对图、能听懂「因为」即可。

## 物质科学

1. **盐和沙子** — 盐会藏进水里（溶解），沙子藏不进去。  
2. **冰块** — 冰是睡着的水，暖和了就化；还是水，只是样子变了。  
3. **磁铁** — 只喜欢铁朋友，不喜欢塑料尺。  
4. **小灯泡** — 电要走一圈（闭合电路）才会亮。  
5. **金属勺** — 热会顺着金属滑到勺柄。

积木模型：小猫「碰到热水」就换红色造型 = 热传过去了。

## 生命科学

1. **植物** — 叶子用阳光做饭（光合作用），没有太阳就又细又弱。  
2. **蚯蚓** — 皮肤要湿才能呼吸，所以喜欢潮土。  
3. **心跳** — 跑步要更多气，心脏就跳得快。  
4. **吃饭** — 要吃好几种食物，一种不够。  
5. **垃圾分类** — 不同垃圾有不同去处，地球更干净。

积木模型：背景换成黑夜，小苗角色变瘦 = 没阳光。

## 地球与宇宙

1. **夏天热** — 阳光照得更直、更烫。  
2. **月亮圆缺** — 月亮自己不会发光，是太阳帮忙照。  
3. **下雨前** — 云又厚又黑，挡住太阳。  
4. **节约水** — 能喝的淡水很少。  
5. **影子** — 中午太阳在头顶，影子最短。

积木模型：太阳角色抬高，杆子的影子造型变短。

## 技术与工程

1. **鞋底花纹** — 抓住地面，不容易滑。  
2. **三角形** — 三条边拉住，塔不容易倒。  
3. **拱桥** — 把重量分到两边。  
4. **宽书包带** — 把重量摊开，不勒肩。  
5. **轮子** — 滚比拖省力。

积木模型：小车有轮子就「移动」快；没轮子就「等待」很久才动一点。
