# E2 第02课：积木王国 🐱

网页关卡：`e2.html` → **🐱 积木王国**

## 对小鱼说（短）

- 中间大方块是 **舞台**，小猫在这里演戏。  
- 左边是 **积木筐**，不同颜色干不同的事。  
- **绿旗** 一按，故事才开始。  
- 积木要 **从上往下** 手拉手，不能东一块西一块。  
- 记住四步：**拼积木 → 排顺序 → 点绿旗试 → 不对就改**。

## 要能分清的积木（看颜色就行）

| 颜色感觉 | 干什么 | 例子 |
| :--- | :--- | :--- |
| 蓝 | 走路、转身 | 移动 10 步 |
| 紫 | 说话、换装 | 说「你好」 |
| 黄 | 什么时候开始 | 当绿旗被点击 |
| 橙 | 再做一遍 / 如果 | 重复执行、如果 |

## 本关小游戏

网页里有「给积木排队」：绿旗 → 向前走 → 说你好。  
选错会退回来，让他再排。
