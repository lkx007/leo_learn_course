## 这条线和 Scratch 课有什么不一样？

仓库里已有完整的 **Scratch 图形化课**（玩、做游戏）。  
E2 课 **不替代** Scratch 主线，专门帮 Leo 应付初赛的四类考题：

| 官网知识点 | 小鱼怎么学 | 网页关卡 |
| :--- | :--- | :--- |
| 图形化编程基础认知 | 舞台、角色、绿旗；拼→排→试→改 | 🐱 积木王国 |
| 图形化建模入门知识 | 模型＝真东西的缩小版 / 简化版 | 🧱 什么是模型 |
| 科学探究与建模关联 | 看→问→猜→试→说；只改一个条件 | 🔍 科学家怎么想 |
| 基础科学常识 | 用图画听「为什么」，再连到积木模型 | 🌈 科学小故事 · 💧 水和空气 · 🔊 声音和光 |

资料来源：**今天《E2 图形化编程建模-初赛测评指南》为主**（场次、进门、设备、页面常开、交卷）；说明会补充题型（20 选 + 10 判、练/赛、Scratch）。E1/E3/E4-E5 只借鉴平台按钮，不采用它们的时间表和编程语言。建模大赛 / 建模 11–18 做成 **「知识点小课」**：先听短故事，再点选择题；广度、深度、递归只用生活比喻。

## 八个关卡（对应网页课）

1. **🎒 准备出发** — 比赛是什么、什么时候考、电脑和小手机怎么摆  
2. **🐱 积木王国** — Scratch 四个区、绿旗、积木排队、**拼排试改**  
3. **🧱 什么是模型** — 玩具车、地球仪、地图、小猫程序都是模型  
4. **🔍 科学家怎么想** — 探究五步 + 对比实验「只改一个」  
5. **🌈 科学小故事** — 物质 / 生命 / 地球 / 工程，每则一个为什么  
6. **💧 水和空气** — 三年级：水、冰、风、蚕宝宝、太阳  
7. **🔊 声音和光** — 四五年级浅讲：声音、重力、电路、种子、食物链  
8. **⭐ 闯关小测验** — 小题库：小鱼/小猫/彩虹/星星/积木/水滴 六套 + 幸运抽题；每套 **20 选 + 10 判，满分 100**  
9. **📚 知识点小课** — 建模大赛 + 建模 11–18，每课 **先讲解、再选择题**

题目上的汉字都带汉语拼音，方便识字。喇叭会一句一句慢慢说。

建议每天 **1 个关卡，20–30 分钟**，考前一天只做错题和设备彩排。
